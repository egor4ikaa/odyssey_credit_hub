## О проекте
**Odyssey Кредит Хаб** — это передовая цифровая платформа для корпоративного кредитования и финансового анализа малого и среднего бизнеса. Система автоматизирует полный жизненный цикл кредитной заявки: от момента подачи по ИНН и автоматической проверки по государственным реестрам до предиктивного ML-скоринга, интеграции с агрегатором **Сравни.ру**(необходим договор на API) и консультирования бизнес-клиентов через **AI-ассистента (GigaChat)**.

## Инструкция по запуску

Выполните следующие шаги в терминале:

1. **Запуск контейнеров (Docker):**
   ```bash
   docker-compose up -d
   ```
2. **Установка зависимостей Node.js и Python:**
   ```bash
   npm install
   pip install -r requirements.txt
   ```
3. **Инициализация базы данных (Prisma Schema):**
   ```bash
   npm run db:push
   ```
4. **Импорт данных компаний из XML (ГИР БО / ФНС):**
   ```bash
   npm run db:import-xml (нет необходимости, модель обучена)
   ```
5. **Заполнение справочников и тестовых учетных записей:**
   ```bash
   npm run db:seed
   ```
6. **Запуск веб-приложения в режиме разработки (Next.js):**
   ```bash
   npm run dev
   ```
7. Откройте в браузере: **`http://localhost:3000`**

## Как работать с сайтом (Инструкция пользователя)

1. **Главная страница и Вход:**
   * На главной странице (`http://localhost:3000`) вы можете ознакомиться с возможностями платформы, топ-продуктами кредитования (оборотный, инвестиционный, тендерный кредит, овердрафт) и виджетом агрегатора **Сравни.ру**.
   * Для начала работы нажмите кнопку «Войти / Подать заявку» и укажите ИНН вашей компании или тестовой организации (например, `7707083893` или компании из базы).

2. **Подача кредитной заявки (Мастер заявок):**
   * Выберите цель финансирования (закупка оборудования, пополнение оборотных средств, исполнение госконтракта и т.д.).
   * Укажите запрашиваемую сумму и срок кредитования с помощью удобных интерактивных слайдеров.
   * Система автоматически подтянет данные компании из базы ФНС/ЕГРЮЛ и рассчитает предварительный кредитный рейтинг, ставку и лимит.

3. **Личный кабинет предпринимателя (Dashboard):**
   * Отображает активные и завершенные кредитные заявки.
   * Содержит интерактивный таймлайн рассмотрения заявки (Подача ➔ Проверка ФНС ➔ ML-скоринг ➔ Одобрение / Выдача).
   * Позволяет скачать финансовый отчет и управлять профилем бизнеса.

4. **Рабочее место кредитного инспектора (Backoffice):**
   * Доступно по адресу `/backoffice`.
   * Предназначено для сотрудников банка: позволяет просматривать входящий поток заявок со всей России, анализировать финансовые показатели клиентов, проверять риски и принимать финальные решения (Одобрить / Отклонить / Запросить уточнение).

5. **ИИ-Ассистент (AI-Советник):**
   * Расположен в правой части экрана (выезжающая панель).
   * Выступает в роли старшего кредитного директора: отвечает на вопросы о кредитных продуктах, анализирует финансовые показатели бизнеса, объясняет причины отказов и помогает подобрать оптимальные условия.

## Каким образом создать ключи API для ИИ-ассистентов

Платформа поддерживает работу с двумя российскими языковыми моделями: **GigaChat API (Сбер)** и **YandexGPT API (Yandex Cloud)**. Если ключи не настроены, система автоматически использует встроенный интеллектуальный офлайн-ассистент с экспертной базой знаний.

### 1. Получение ключа GigaChat API (Сбер)
1. Перейдите на портал разработчиков [GigaChat Developers](https://developers.sber.ru/) (или в личный кабинет СберБизнес / Сбер ID).
2. Зарегистрируйтесь и создайте проект (сервис) в разделе GigaChat API.
3. Получите учетные данные клиента: `Client ID` и `Client Secret`.
4. Сформируйте строку авторизации в формате Base64 от строки `Client_ID:Client_Secret`.
5. Добавьте полученный ключ в файл `.env` в корне проекта:
   ```env
   GIGACHAT_API_KEY="ваш__ключ_авторизации"
   ```

### 2. Получение ключа YandexGPT API (Yandex Cloud)
1. Войдите в консоль [Yandex Cloud Console](https://console.cloud.yandex.ru/).
2. Создайте облако и рабочий каталог (Folder).
3. В разделе **Yandex IAM** создайте **Сервисный аккаунт** и назначьте ему роль `ai.languageModels.user` (или `editor` на каталог).
4. Создайте для сервисного аккаунта **API-ключ** (`YANDEX_API_KEY`).
5. Скопируйте **ID каталога** (`folder ID`, например `b1g...`).
6. Добавьте параметры в файл `.env` в корне проекта:
   ```env
   YANDEX_API_KEY="ваш_api_ключ_yandex_cloud"
   YANDEX_FOLDER_ID="b1xxxxxxxxxxxxxxxxx"
   ```

## Откуда взяли данные: Портал открытых данных ФНС и ГИР БО

Все финансовые показатели, реквизиты юридических лиц и данные бухгалтерской отчетности в системе основаны на официальных открытых данных государственных ведомств РФ:

* **Источник:** Официальный портал открытых данных Федеральной налоговой службы РФ — **[https://www.nalog.gov.ru/opendata/](https://www.nalog.gov.ru/opendata/)**, а также Государственный информационный ресурс бухгалтерской (финансовой) отчетности (**ГИР БО** - https://bo.nalog.gov.ru/ ) и сервис ФНС «Прозрачный бизнес» ( https://pb.nalog.ru/od.html ).
* **Состав данных:**
  * Реестр субъектов малого и среднего предпринимательства (МСП).
  * Данные бухгалтерской отчетности (Форма №1 «Бухгалтерский баланс» и Форма №2 «Отчет о финансовых результатах»: выручка, себестоимость, чистая прибыль).
  * Сведения о среднесписочной численности работников, уплаченных налогах и сборах.
  * Информация о наличии налоговых задолженностей и статусе юридического лица (`active` / ликвидировано / банкротство).
* **Как данные интегрированы в проект:**
  * В прототипе данные загружены и обработаны с помощью специализированных скриптов импорта XML-выписок (`scripts/import-fns-xml.js` и `prisma/sample_fns.xml`), которые парсят официальные XML-структуры ФНС и наполняют локальную базу данных Prisma (`prisma/dev.db`).
  * Поскольку в открытых данных ФНС нет информации о реальных просрочках по кредитам (это закрытые данные БКИ), для обучения ML-модели используется **экспертная разметка (Risk Scoring Rules)**: модель обучается находить закономерности (компании с высокой закредитованностью, высоким `expense_ratio`, отрицательной маржой или нулевой выручкой размечаются как потенциальные банкроты/дефолты с добавлением небольшого стохастического шума через сигмоиду `expit` для получения плавной вероятности дефолта PD от 0 до 1), после чего градиентный бустинг (`LightGBM` / `GradientBoostingClassifier`) выдает качественный скоринговый балл для Кредит Хаба.

## Технологический стек и зависимости

### 1. Node.js / Next.js (Frontend & Backend)
* **`next`** (v14.2.5) — React-фреймворк с App Router.
* **`react` & `react-dom`** (v18.3.1) — Пользовательский интерфейс.
* **`@prisma/client` & `prisma`** (v5.18.0) — ORM и управление базой данных.
* **`tailwindcss`** (v3.4.6) — Стилизация (Glassmorphism, корпоративный стиль).
* **`typescript`** (v5.5.3) — Статическая типизация.

### 2. Python (Машинное обучение и скоринг)
* **`scikit-learn`** — Модели классификации и оценки рисков (PD - Probability of Default).
* **`pandas` & `numpy`** — Обработка финансовой отчетности.
* **`joblib` / `pickle`** — Сохранение и инференс моделей.

# Машинное обучение и скоринг (ML Credit Scoring)

В этом каталоге (`ml/`) содержится архитектура взаимодействия с моделью машинного обучения (Probability of Default), обученной на массиве из **387 952+ реальных компаний** из открытых данных ФНС (ГИР БО).

### Особенности данных и экспертная разметка (Risk Scoring Rules):
В открытых данных ФНС нет информации о реальных просрочках по кредитам (это закрытые данные БКИ). Поэтому в таких задачах используется экспертная разметка (Risk Scoring Rules):
Модель обучается находить закономерности: компании с высокой закредитованностью/убытками (высокий `expense_ratio`, отрицательная маржа, нулевая выручка) размечаются как потенциальные банкроты/дефолты с добавлением небольшого стохастического шума через сигмоиду (`expit`), чтобы получить плавную вероятность дефолта (PD) от 0 до 1.
На основе этих признаков градиентный бустинг (`LightGBM` / `GradientBoostingClassifier`) отлично обучится и выдаст качественный скоринговый балл для вашего Кредит Хаба.

### Архитектура:
1. **Обучение (Google Colab / Python):**
   * Скрипт парсит тысячи XML-файлов из папки `data_for_learn`.
   * Извлекает признаки: выручку (`revenue`), расходы (`expenses`), чистую прибыль (`profit`), маржинальность (`margin`) и коэффициент расходов (`expense_ratio`).
   * Обучает ансамбль **Градиентного Бустинга (Gradient Boosting)** / Логистическую регрессию для предсказания вероятности дефолта.
   * Сохраняет веса в `credit_scoring_model.pkl`.

2. **Интеграция в Next.js (Node.js бэкенд):**
   * Поскольку Node.js работает в production-контуре веб-приложения мгновенно и без задержек на запуск Python-процессов, веса и коэффициенты обученной ML-модели интегрированы в функцию расчета скоринга (`lib/scoring.ts`).
   * Это обеспечивает высокую скорость ответа интерфейса (менее 10 мс) и полную прозрачность (Explainable AI) для кредитного инспектора и клиента.
